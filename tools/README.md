# tools

Scripts that are not part of the paper's pipeline but are kept for reference.
Each script adds the repository root to its import path, so it can be run from
the root or from its own folder.

| Folder | Contents |
|---|---|
| `prior_correction/` | Earlier exploratory scripts for the class-prior correction, superseded by `experiments/run_experiments.py` |
| `diagnostics/` | One-off checks that found the flooding sentinel artifact fixed in pipeline v3 |
